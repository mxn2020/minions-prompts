## Pourquoi versionner les prompts ?

<CardGrid stagger>
  <Card title="Historique complet des versions" icon="pencil">
    Chaque modification est suivie via des relations `follows` — ne perdez plus jamais un changement.
  </Card>
  <Card title="Interpolation de variables" icon="add-document">
    `{{variable}}`, `{{#if condition}}`, `{{#each items}}` — des templates puissants.
  </Card>
  <Card title="Développement piloté par les tests" icon="approve-check">
    Créez des cas de test avant de modifier les prompts — détectez les régressions.
  </Card>
  <Card title="Comparaison A/B" icon="setting">
    Exécutez deux versions contre les mêmes tests et comparez les résultats.
  </Card>
</CardGrid>
