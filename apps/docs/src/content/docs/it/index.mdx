## Perché versionare i prompt?

<CardGrid stagger>
  <Card title="Cronologia completa delle versioni" icon="pencil">
    Ogni modifica viene tracciata tramite relazioni `follows` — non perdere mai più un cambiamento.
  </Card>
  <Card title="Interpolazione di variabili" icon="add-document">
    `{{variable}}`, `{{#if condition}}`, `{{#each items}}` — template potenti.
  </Card>
  <Card title="Sviluppo guidato dai test" icon="approve-check">
    Crea casi di test prima di modificare i prompt — rileva le regressioni.
  </Card>
  <Card title="Confronto A/B" icon="setting">
    Esegui due versioni contro gli stessi test e confronta i risultati.
  </Card>
</CardGrid>
