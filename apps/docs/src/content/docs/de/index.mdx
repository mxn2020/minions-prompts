## Warum Prompts versionieren?

<CardGrid stagger>
  <Card title="Vollständige Versionshistorie" icon="pencil">
    Jede Änderung wird über `follows`-Relationen nachverfolgt — nie wieder Änderungen verlieren.
  </Card>
  <Card title="Variablen-Interpolation" icon="add-document">
    `{{variable}}`, `{{#if condition}}`, `{{#each items}}` — leistungsstarke Vorlagen.
  </Card>
  <Card title="Testgetriebene Entwicklung" icon="approve-check">
    Erstellen Sie Testfälle, bevor Sie Prompts ändern — fangen Sie Regressionen ab.
  </Card>
  <Card title="A/B-Vergleich" icon="setting">
    Führen Sie zwei Versionen gegen dieselben Tests aus und vergleichen Sie die Ergebnisse.
  </Card>
</CardGrid>
