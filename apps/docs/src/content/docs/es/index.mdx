## ¿Por qué versionar prompts?

<CardGrid stagger>
  <Card title="Historial completo de versiones" icon="pencil">
    Cada cambio se rastrea mediante relaciones `follows` — nunca pierdas un cambio.
  </Card>
  <Card title="Interpolación de variables" icon="add-document">
    `{{variable}}`, `{{#if condition}}`, `{{#each items}}` — plantillas poderosas.
  </Card>
  <Card title="Desarrollo guiado por pruebas" icon="approve-check">
    Crea casos de prueba antes de modificar prompts — detecta regresiones.
  </Card>
  <Card title="Comparación A/B" icon="setting">
    Ejecuta dos versiones contra las mismas pruebas y compara los resultados.
  </Card>
</CardGrid>
